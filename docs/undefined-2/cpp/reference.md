# Reference

레퍼런스 타입 연산자 : &  C 언어 주소 연산자랑 같음&#x20;

```
// 포인터를 이용한 값 변경
int change_vlaue(int* value)
{
	*value = 20;
	return 0;
}
// 참조자를 이용한 값 변경
int change_value_ref(int& value)
{
	value = 30;
	return 0;
}
```

위 함수는 동일하게 동작한다 즉 주소지에 있는 원본을 변경한다는 것

```
int y = 5;
int& ref = y; // 참조자 선언 및 초기화
std::cout << "y: " << y << std::endl; // y 값 출력
std::cout << "ref: " << ref << std::endl; // 참조자 값 출력
```

반드시 선언과 동시에 초기화 해야함 lazy 하게 초기화할 수 없음



```
int& ref_a = a; 
// 참조자 선언 및 초기화
ref_a = b; 
// a = b ; 와 동일한 효과를 가진다. ref_a는 a를 참조하고 있기 때문에 ref_a에 값을 할당하면 a의 값이 변경된다.
```



```
	int k = 0;
	int& ref_k = k; // 참조자 선언 및 초기화
	std::cout << "k: " << &k << std::endl; // 포인터 값 출력 (d의 주소) 메모리 상에 존재하지 않음
	std::cout << "ref_k: " << &ref_k << std::endl; // 포인터 값 출력 (d의 주소) 메모리 상에 존재하지 않음 변수 k와 ref_k는 같은 메모리 주소를 공유하지만,
	//ref_k는 별도의 메모리 공간을 차지하지 않는다. 따라서 &ref_k를 출력하면 k의 주소가 출력된다.
```

참조자는 메모리 상에 따로 주소가 존재하지 않음 따라서 잠조자 변수의 주소값을 출력하면 당연하게도 원본의 메모리 주소가 출력됨

```
int& arr[2] = { x1, x2 };
```

참조자 타입의 배열은 생성할 수 없음 배열의 기본이 해당 값을 복사 후 저장하는 것이 아니라 메모리 주소값을 참조하는 것인데, 참조자는 메모리 주소가 없을 수 있기 때문에 컴파일 오류가 발생한다.



```
// 지역변수의 레퍼런스를 반환하는 함수
int& return_local_ref() {
	int local_var = 10;
	return local_var; // 지역변수의 레퍼런스를 반환하면 런타임에러 발생
}
```

위 함수가 잘못된 점은 로컬 변수의 참조자를 반환하고 있기 때문 해당 함수가 종료되면 해당 로컬 변수는 정리가됨 따라서 Undifined behavior 가 됨 이상한 값이 반환될 수 있음 근데 왜 이따구로 만든진 모르겠음
