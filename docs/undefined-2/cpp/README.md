# C++ 학습 노트

## 주교재

이재범, **『씹어먹는 C++』 v.2020.06.17**, 전체 약 983쪽. 원문 https://modoocode.com

이 책은 C의 기본 문법(조건문·반복문·포인터)을 익혔다는 전제로 설명하며, 본문은 C++17까지의 주요 기능을 중심으로 한다. VS 2017 등 당시 개발 환경 설명은 현재 환경과 다를 수 있으므로 설치는 현재 Visual Studio/MSVC 기준으로 진행한다.

## 장별 실습 체크리스트

* [x] 1\~2장: C++ 시작, 컴파일과 기본 코드
* [x] 3\~4장: 참조자, 객체에 들어가기 전 문법과 메모리
* [ ] 5장: 클래스, 생성자/복사 생성자/소멸자, const, 문자열 클래스, explicit/mutable
* [ ] 6장: 연산자 오버로딩, N차원 배열 프로젝트
* [ ] 7\~8장: 상속·다형성·가상 함수, 표준 입출력
* [ ] 9장: 엑셀 프로젝트 1\~2부
* [ ] 10장: 템플릿·가변 템플릿·템플릿 메타프로그래밍
* [ ] 11장: vector/map/unordered\_map, 알고리즘, string/string\_view
* [ ] 12\~13장: 예외 처리, 우측값/이동 의미론/완벽 전달
* [ ] 14\~15장: 스마트 포인터, 함수 객체
* [ ] 16장: 스레드·mutex/조건 변수·atomic·비동기·ThreadPool
* [ ] 17\~19장: 유니폼 초기화, constexpr, decltype/decval
* [ ] 20장: type\_traits, regex, random/chrono, filesystem, 유틸리티
* [ ] 21\~22장: 마무리, Makefile/빌드 지식

**목표:** 2027-05-24까지 전 예제의 손코딩과 실험 이력을 1회 완료. 책의 깊은 템플릿 메타프로그래밍 등에서 진도가 지연되면 월말 재산정한다.
