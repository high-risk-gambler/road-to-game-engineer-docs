# 알고리즘 풀이

**기본 빈도:** 주 3회. 어려운 문제 개수보다 **내가 설명 가능한 풀이**를 우선한다.

## 단계별 주제

1. 배열/문자열, 시뮬레이션, 정렬
2. 스택/큐, 해시맵, 투 포인터
3. 이진 탐색, 재귀, 백트래킹
4. 트리, BFS/DFS, 그래프
5. 최단 경로, 동적 계획법, 기초 최적화

## 풀이 기록 형식

- 문제 링크 / 날짜:
- 첫 접근과 막힌 점:
- 시간/공간 복잡도:
- 경계 조건:
- 다른 사람에게 설명할 수 있는가:
- 직접 작성한 코드는 개발 저장소 커밋으로 연결:

AI는 풀이를 즉시 보여주는 대신 **반례나 다음 힌트**를 요청한다.
