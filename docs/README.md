# Engineering Journal 🎮

> 365일 동안 학습을 **실행 결과**, **기술적 판단**, **회고**로 축적해 FPS 게임 개발자 채용에 도전하는 공개 개발 일지.

- **기간:** 2026-11-25 ~ 2027-11-24
- **우선 목표:** 대형 게임사 C++ / Unreal Engine FPS 게임플레이 개발자 취업
- **탐색 분야:** 게임 서버 개발
- **제작 목표:** 콘솔 전투 시뮬레이터 → UE5 전투 프로토타입 → 네트워크 기능과 성능 검증을 갖춘 FPS 포트폴리오
- **코드 저장소:** [road-to-fps-engineer](https://github.com/high-risk-gambler/road-to-fps-engineer)
- **계획 관리:** [GitHub Issues](https://github.com/high-risk-gambler/road-to-fps-engineer/issues)

{% hint style="important" %}
**학습 규칙:** 모든 코드는 직접 손으로 작성한다. 생성형 AI는 설명, 힌트, 설계 검토, 코드 리뷰와 디버깅 분석에 집중하고, AI가 작성한 완성 코드를 복사해 제출하지 않는다.
{% endhint %}

## 이 문서의 읽는 순서

1. [1년 로드맵](roadmap/year-plan.md)을 보고 지금의 위치를 확인한다.
2. [이번 주 계획](roadmap/weekly-plan.md)에서 실행할 최소 목표를 정한다.
3. [일일 학습 템플릿](daily/template.md)으로 5~10분 기록한다.
4. [주간 회고](daily/weekly-review.md)에서 다음 주의 우선순위를 조정한다.
5. [포트폴리오](portfolio/README.md)에 검증 가능한 성과만 연결한다.

매일의 모든 코드와 풀이를 GitBook에 복사하지 않는다. 코드는 개발 저장소에, **왜 그렇게 구현하고 어떻게 검증했는지**는 여기 적는다.
