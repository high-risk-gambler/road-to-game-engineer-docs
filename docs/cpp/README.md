# C++ 학습 노트

## 학습 순서

1. 자료형, 함수, 제어문, 헤더/소스 분리, 컴파일
2. 클래스, 생성자/소멸자, 캡슐화, 불변식
3. 포인터/참조, const, 값/참조 전달, 메모리 모델
4. RAII, 복사/이동 의미론, 스마트 포인터
5. STL 컨테이너, 반복자, 알고리즘, 복잡도
6. 디버거, 경고, 테스트, 성능 측정

**첫 구현 과제:** 콘솔 Player/Weapon 전투 모델. HP가 음수가 되거나 탄약이 상한을 넘어가는 예외 상황을 직접 테스트한다.

각 개념마다 **정의 → 내가 손으로 작성한 최소 예제 → 예상과 실제 → 게임에 쓰이는 이유** 순서로 정리한다.
