# 1년 로드맵

**기간:** 2026-11-25 ~ 2027-11-24

취업은 보장할 수 없으므로 학습 시간보다 **작동하는 결과물과 설명 가능한 판단**을 기준으로 진척을 평가한다.

| 구간 | 주요 목표 | 검증할 산출물 |
|---|---|---|
| 1개월 | 순수 C++ 2주 + UE5 시작 2주, 기본 알고리즘 습관 | 콘솔 전투 게임, UE5 공격/피격 실습 |
| 2~3개월 | C++ 메모리/객체 수명, 자료구조, 게임 수학, UE5 컴포넌트 | 입력·이동·전투 루프를 갖춘 FPS 프로토타입 |
| 4~6개월 | 게임플레이 구조, 충돌/애니메이션, 디버깅 및 최적화 | 플레이 가능한 전투 수직 슬라이스 + 시연 영상 |
| 7~9개월 | 게임 네트워크 기초, 복제·지연·동기화, 코드 품질 | 멀티플레이 기능 실험, 재현 가능한 성능 기록 |
| 10~12개월 | 포트폴리오 정제, C++/CS/알고리즘 면접, 지원 | 소스/기술 문서/영상/이력서 및 지원 기록 |

## 첫 4주

- **11/25–12/01:** C++ 기초, Player/Weapon 클래스 설계, HP/탄약 불변식 테스트. 처음에는 터미널 기반 콘솔 전투 게임으로 구현한다.
- **12/02–12/08:** 객체 수명, 참조/포인터, RAII, STL, 테스트.
- **12/09–12/15:** Unreal Engine 5 프로젝트 시작, C++ 클래스와 기본 입력/이동.
- **12/16–12/24:** 공격·피격·HP·탄약·디버깅.

## 병행하는 세 축

- **C++/CS:** 원리를 이해하고 작은 예제로 직접 증명한다.
- **게임 제작:** 매주 화면 또는 실행 가능한 프로그램으로 확인한다.
- **알고리즘:** 초기에는 **주 3회**, 풀이를 외우지 않고 복잡도를 설명한다.

3. 코드를 보지 않고 설계와 선택 이유를 말할 수 있는가?
