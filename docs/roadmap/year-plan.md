# 1년 로드맵 — 『씹어먹는 C++』 기반

**기간:** 2026-11-25 ~ 2027-11-24  
**주교재:** 이재범, 『씹어먹는 C++』, 2020-06-17 판본(첨부 PDF 약 983쪽). 원문: https://modoocode.com

**핵심 원칙:** 책의 모든 코드 예제를 **직접 타이핑하고 컴파일·실행·분석**한다. 다만 책을 다 끝낼 때까지 게임 제작을 미루지 않는다. 3주 차부터 UE5를 병행한다.

> 이 책은 기본 C 문법(반복문·포인터 등)을 알고 있다고 가정하며, 주로 C++17까지 다룬다. 필요할 때 기본 문법을 별도로 보충하고, 후반에는 최신 C++와 UE 전용 API를 공식 문서로 보완한다.

## 첫 4주 상세

- **W02 12/02–12/08:** 5장 클래스·생성자·복사·소멸자·const. 책 예제 재현 + 콘솔 Player/Weapon 불변식 테스트.
- **W03 12/09–12/15:** 5장 문자열 클래스/explicit/mutable 복습 + UE5 프로젝트 생성/입력·이동.
- **W04 12/16–12/24:** 6장 연산자 오버로딩 입문 + UE5 공격/피격·월말 점검.

## 반복 학습 방식 — 예제 한 개마다

1. 읽기 전에 결과 예측
2. **예제 전체를 손으로 작성**하여 빌드/실행
3. 입력·경계 조건 한 가지 수정 후 결과 확인
4. 핵심 개념을 설명하는 3~5줄 기록
5. 게임 코드와 연결할 수 있는지 판단

**책의 예제 코드 전체를 GitBook이나 공개 저장소에 복제하지 않는다.** 원본은 저작권이 있으므로 개인 학습용으로 타이핑해 실행하고, 공개 저장소에는 자신의 변형 실험·테스트·프로젝트 및 출처를 기록한다.

## 주간 시간 배분 (하루 약 3시간 가정)

- 책 예제와 변형 실습: 4~5회 × 60~90분
- UE5/콘솔 게임 구현: 3회 × 60~90분 (3주 차부터)
- 알고리즘: 주 3회 × 30분
- CS와 주간 회고: 주 1회 × 30~60분

초반 두 주는 UE5 시간을 콘솔 프로젝트로 전환한다. 실제 가용 시간이 적으면 **하루 책 예제 한 개 + 짧은 구현**만 지키고 추가 범위는 미룬다.
