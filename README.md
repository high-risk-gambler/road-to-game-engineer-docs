## 학습 원칙

1. **모든 학습 코드와 구현은 직접 손으로 작성한다.**
2. 생성형 AI는 개념 설명, 힌트, 코드 리뷰, 디버깅 분석을 중심으로 사용한다. 완성 코드를 복사해 제출하지 않는다.
3. C++ 기초를 익히는 동시에 매주 작은 실행 결과를 만든다. 처음 2주는 순수 C++, 3주차부터 UE5를 병행한다.
4. 알고리즘을 주 3회 점진적으로 푼다.
5. 매일 기록은 짧게, 매주 회고는 깊게, 월말에는 취업 관점에서 검증한다.
